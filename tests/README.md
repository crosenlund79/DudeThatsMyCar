# Testing baseline (Godot 4)

Testing starts with the **first implemented module**, not with speculative starter-pack scaffolding.

- Pick **GUT or GdUnit4**, compatible with the pinned Godot 4.x minor version, once in `docs/PROJECT_BRIEF.md`.
- A **module** is an implemented component with one responsibility (usually `src/<module>/`). Give its essential logic headless automated tests where feasible.
- An **important interaction** is a contract between two or more modules that affects gameplay/state. Add automated integration tests for those contracts, updating them when either side changes.
- Visual, animation, audio and control **feel** also require a short, relevant **manual checklist**, since headless tests cannot establish quality of presentation.
- Document exact commands to run logic tests headlessly, and keep tests practical. Do not claim tests passed if Godot, the runner or dependencies are unavailable; state **not run and why**.
- Asset resolver tests must cover override precedence, missing/invalid fallback, supported formats and override-root selection, using an injected temporary folder (see `assets/README.md`). Exported-game verification follows guideline 4; if no export was approved, report it as pending.

## In this project

- **Run everything:** `godot --headless --path . --import` (once, and again after adding a `class_name` script), then `godot --headless --path . --fixed-fps 60 -s addons/gut/gut_cmdln.gd`. `--fixed-fps 60` runs physics at full speed regardless of real time.
- **Scene tests** (`tests/integration/`) start the real game scene with a scripted command source instead of the keyboard and mouse (`tests/support/city_test.gd`: `hold`, `press_e`, `walk_to`, `seat_in`, `park`; M003: `answer`, `answer_with`, `talk_to`, `at_the_streetcar_stop`; M004: `path_in_room` and `walk_in_to`, which walk into a room off the sidewalk and round its furniture with the normal movement). They never write the player's save file (`main.save_path = ""`) or sound levels (`main.settings_path = ""`), skip the M005 opening narration (`main.opening_enabled = false`; `test_opening.gd` starts the scene itself with a temporary save file), and run with the passers-by and traffic cleared unless the script sets `quiet_streets = false` (`test_street_life.gd`). The night begins at home since M003; street tests step out to the streetcar stop first. One test file (`test_input_mapping.gd`) drives the game through Godot's real input actions.
- **Screenshots** need a display: `xvfb-run -a godot --path . --rendering-driver opengl3 --resolution 1280x720 -s tests/support/screenshot_tour.gd -- <output dir> [street walk drive garage river alley hotel wide ...]` (M003 shots: `home traffic steer club augie barber grocery eddie squad_car wake`; M004: `cars grocery_door grocery_marker drive_markers`; M005: `opening`, the monologue in real time; M006: `bird bird_talk lefty gunfight ward_map vet status morgue`; M007: `job_offer lindqvist_tells job_map confront fight report`; M008: `yards yards_dock yards_sidings border_south crossing square bijou church border_west city_map city_map_wide city_map_square police_shooting`; M009: `incident incident_broken_up incident_stop dutch crate feeney film_can dump_truck school_bus wheels wheels_lock`; see the script's header).
- **District streaming measurements (M008):** `xvfb-run -a godot --path . --rendering-driver opengl3 --resolution 1280x720 -s tests/support/district_probe.gd` drives across each border and prints build times, frame times by phase, memory and nodes with one and two districts, unloading and rebuilding, and the frame rate in each district with and without its street life and lamps.
- **Frame rate:** `xvfb-run -a godot --path . --rendering-driver opengl3 -s tests/support/perf_probe.gd` prints the frame rate at home, inside the Copper Owl, on Marlowe Avenue with traffic, driving, and with lamps, haze, vignette, ground and buildings switched off in turn.
- **Asset list:** `docs/ASSET_SPECS.md` is generated from the catalogue (`godot --headless --path . -s tests/support/asset_specs_writer.gd`); a unit test fails when it is out of date.
- **Skipped files:** GUT skips a test file that fails to parse and still reports "All tests passed". After adding or changing tests, check the script count in the summary (and the log for `Parse Error`).
- **Long scenarios** (police pursuit, driving routes) run in simulated time with `--fixed-fps 60`; helpers `drive_route` (a careful W / A / S / D driver), `click` and `aim_for` live in `tests/support/city_test.gd`.
- **Sound (M005):** the headless run uses Godot's dummy audio driver, so nothing is heard and playback positions do not advance. Sound tests check what can be checked without a sound card: the levels, filters and pan the mixing rules give (`test_soundscape_mix`), the routing, glides and continuity in the game (`test_soundscape`: the Copper Owl's music stays one player, started once, through doors, drives and sleep), the opening's timing and hand-over (`test_opening`), and the override and fallback paths for OGG, WAV and MP3 (`test_asset_resolver`). Whether it *sounds* right is the listening section of `tests/manual/m005_the_city_has_ears_checklist.md`; never report it as verified by the automated tests.
- **Multi-night play:** `test_ward_life` (unit) plays seven nights of the pure economy, an honest and a greedy henchman side by side, and prints the ward each morning; `test_the_city_has_ears` (integration) plays three nights in the game with the normal controls, saving and loading midway.
- **People in scene tests (M006):** `city_test.gd` marks every first-meeting voice line as heard unless the script sets `meet_people = true` (`test_voices`, `test_the_bird`, `test_dangerous_company`), so older tests open straight on the usual pages. Recorded voices advance on the test clock (the dummy audio driver does not play them), so queued lines and fades are tested by time.
- **Smoke test (M006):** `test_dangerous_company.gd` plays one night with every M006 feature in turn (voices, the Bird, Eddie's wares, Lefty, wounds and the vet, a witnessed car theft, the map), sleeps into the next evening, saves and loads.
- **Fistfights (M007):** scene tests play the dial by waiting for the needle to enter the zone and sending the real Space action (`CityInput.HANDBRAKE`) through `main._unhandled_input` (`test_fistfight`, `test_confronting_lefty`, `test_a_job_for_rourke`); whether the timing *feels* fair is in `tests/manual/m007_a_job_for_rourke_checklist.md`.
- **Districts in tests (M008):** scene tests start with only the ward built; a test about another district calls `main.world.load_now(id)` or drives there (the streamer builds it ahead, a slice a frame). `quiet_streets` clears the neighbours' street life too. `tests/support/toy_district.gd` makes small districts for testing the streamer on its own. The playthrough is `test_beyond_riverside_ward.gd`.
- **Playthrough (M007):** `test_a_job_for_rourke.gd` plays the job in one night with the normal controls (Rourke's offer, Lindqvist, Eddie, the map, walking up to Lefty, the fight won on the dial, the report), then the next evening's talk and a saved and loaded game.
- **The city's incidents (M009):** scene tests replace tonight's plan with the one incident they are about (`main.incidents.plan = [{id, kind, spot, at, tries}]`) and move the night on with the clock (`_skip` in `test_city_incidents.gd`), putting Danny far away first (an incident never begins within 650 px of him) and snapping the camera to him (incident people are drawn only near the camera). `test_incidents_off_screen.gd` covers the state-only side (districts not built, let go, a whole night on its own, a reloaded night); the pure model is `tests/unit/test_street_incidents.gd`.
- **Opportunities and heavy vehicles (M009):** `test_dutchs_crate.gd`, `test_the_bijous_reel.gd` (in the game), `test_opportunities.gd` (pure: nights, expiry, pay, memory, talk, Rourke); `test_heavy_vehicles.gd` (pure handling, mass, collision) and `test_heavy_vehicles_in_town.gd` (taking, driving out of the dock and round a corner, a shoved car and a wall, the bus across a border). A test about a neighbouring district puts Danny there before `load_now`, or the streamer lets it go again on the next frame.
- **Measurements (M009):** `xvfb-run -a godot --path . --rendering-driver opengl3 --resolution 1280x720 -s tests/support/incident_probe.gd` prints a night of incidents run as state, the M009 work per frame with nothing going on and with two incidents in view, and the frame rate in each case (and at Dutch's, and driving the bus).
- **Playthrough (M009):** `test_the_city_doesnt_sleep.gd` plays three nights with the normal controls: an argument that runs its course without Danny, Dutch's crate driven up to Novak's, a handoff come upon half way through, the Bijou's show cancelled because Danny never went, the talk reaching Rourke two nights later, Rourke's job untouched, a saved and loaded game.
- **Screenshots (M010):** `truck_found weather_clear weather_rain weather_fog weather_rain_fog fog_alley fog_headlights drowsy map_labels map_medium ping park sitting back_room poker_game thompson cafe_packard cafe_blast cafe_aftermath emergency`; the grit, fence and shadow pictures are the older `street`, `alley` and `yards_sidings` shots taken again (all in `docs/screenshots/m010/`).
- **Measurements (M010):** `xvfb-run -a godot --path . --rendering-driver opengl3 --resolution 1280x720 -s tests/support/m010_probe.gd` prints the frame rate on Marlowe Avenue in each weather and the weather's own work, then with the card table open, a Thompson burst, the café's film and fire, and the emergency at the kerb, and their own updates a frame. Startup and streaming costs of the grime, shadows and fog cover are in `docs/DISTRICT_STREAMING.md` (`district_probe.gd`).
- **Weather in tests (M010):** `main.weather.force(state)` holds a state ("" lets the night's course run); `main.weather_override` holds one through sleep. Scene tests start in the first night's weather (rain) unless they force another.
- **Poker (M010):** the rules are tested without the scene (`test_holdem`: every betting rule, side pots, odd chips, and 300+ hands of random legal play with the chips counted after every action; `test_hand_rank`; `test_poker_brain`; `test_poker_night`: the books from buy-in to cash-out). Scene tests (`test_card_game`) speed the card players up through `PokerView.think`, press Space through whatever is on show (`PokerView.pacing.waiting()`; the next hand is dealt the moment a result is dismissed, so a helper that counts hands stops at a result beat), and play through the real keys (`main._unhandled_input` with 1-4, the arrows, Space pressed and let go, Esc). The pacing itself: `test_poker_pacing` (unit: beats from the table's events, one beat a press, a held key, run-outs a street at a time, side pots; integration: the pause, the prompt, a held Space, Space on Danny's turn, the board and the showdown, the night's clock).
- **Time passing and moments (M010):** sitting with Space held runs the clock twenty times faster; a test that must not skip something adds its minute to `main.moments` (the café's blast does this itself). The café's film runs on the process clock; tests skip it with `main.cafe_film.skip()` once they have checked it began (the blast and everything after still happen).
- **Playthrough (M010):** `test_the_darker_side.gd` plays two nights with the normal controls: a run in the rain, Eddie's Thompson borrowed, Rourke's café job taken, the parcel bought, three hands at the back-room table with every cent counted, the parcel under the Packard, the bench, the film, the emergency, the map's names, Rourke's pay, sleep, a saved and loaded game, the wreck the next night, the Thompson given back.
