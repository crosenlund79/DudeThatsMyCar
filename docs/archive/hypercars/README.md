# HyperCars archive

These documents describe **HyperCars**, the racing game this project was copied from (racing rules, circuits, championship, garage economy, network play, voice, music, the HyperCars project brief and backlog). The racing game was retired in Milestone 001 of *Chicago, 1932*; its code and assets remain in this repository's history (commit `c6f7511`) and in the original HyperCars repository.

They are kept for technical reference only. Nothing here is a requirement for *Chicago, 1932*; see `docs/PROJECT_BRIEF.md` for the current record.
