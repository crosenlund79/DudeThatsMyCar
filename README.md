# Chicago, 1932 (working title)

A top-down, hand-painted gangster sandbox set in Prohibition-era Chicago, built in Godot 4.7 (GL Compatibility). It grew out of a copy of the HyperCars racing game, whose driving physics it keeps; everything racing-specific has been retired. Design: `docs/chicago_1932_game_design_document.md`. Decisions and the current objective: `docs/PROJECT_BRIEF.md`.

**Milestone 001 (first playable visual prototype):** one small neighbourhood at night — the Riverside Ward. Walk the streets, alleys and gangways, get into a parked 1930s car and drive. No police, traffic, people, missions or combat yet. A guide to the district: `docs/RIVERSIDE_WARD.md`.

## Run it

Open the project in Godot 4.7.x and press Play (the run scene is `src/main/main.tscn`), or from a terminal:

```bash
godot --path .
```

You start at the streetcar stop on Marlowe Avenue, between the Copper Owl supper club and Hotel Marlowe. The cream roadster is parked at the curb a few steps south.

| On foot | | Driving | |
| --- | --- | --- | --- |
| W A S D | walk | W | accelerate |
| Mouse | aim (left button reserved for shooting) | S | brake, then reverse |
| E | get into the nearest parked car | A / D | steer |
| | | Space | handbrake |
| | | E | get out (the car stops first) |

F1 shows the controls card, Esc pauses (Q quits while paused). Arrow keys mirror WASD.

## Replace the art and sound

Every image and sound is a `template_` file in `assets/` that you can override by dropping your own file into `custom/` (in the project while developing, or next to an exported Windows/Linux game, no rebuild needed; restart the game to see it). The full list with sizes and override paths: `docs/ASSET_SPECS.md`; the rules: `assets/README.md`. The template art is generated by `tools/template_art/` (Python with Pillow and numpy).

## Layout

| Folder | What lives there |
| --- | --- |
| `src/driving/` | car model and car scene (from HyperCars, extended for the city), the two vehicle types |
| `src/city/` | the district layout, the city builder, buildings in perspective, night atmosphere |
| `src/actors/`, `src/player/` | the gangster on foot; the player controller (walking, driving, getting in and out) |
| `src/camera/`, `src/ui/`, `src/presentation/` | camera, HUD, lights and sound of the car |
| `src/assets/` | the override resolver and the asset catalogue |
| `src/main/` | the composition root (run scene) |
| `docs/` | brief, rules, design document, asset list, district guide; `docs/archive/hypercars/` keeps the racing game's documents |

Working rules for Claude Code: `CLAUDE.md` and `docs/GODOT_CLAUDE_GUIDELINES.md`.
